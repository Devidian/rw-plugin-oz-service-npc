# OZ Service NPC 0.1.0

- First public release of persistent Restorer and Augmenter NPC endpoints.
- World-local name, outfit and augmentation catalogues can be adapted without
  overwriting existing world files during updates.
- The radial menu exposes the shared Info / Status panel to players; endpoint
  creation and management remain administrator-only.

Requires OZ Tools, OZ Wallet and OZ Mail at runtime.
