# OZ Service NPC 0.5.0

- Authorized managers can give global and faction Service NPCs random catalog clothing or a copy of their currently worn clothing. Only NPC clothing changes; the player's inventory and appearance remain intact.
- Selected clothes are stored with the NPC and restored after plugin reload or server restart. Existing NPCs keep their previous outfit until changed.
- The Augmenter now accepts the listed axes, knives, hammers, scythes, sickles, chainsaw, and mining drill as well as its previous weapons. Existing improvement tiers, prices, and order handling still apply.

Keep the Service NPC database when updating. Faction NPCs require OZ - Factions 0.4.0 or newer. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
